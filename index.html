Add Students
Paste Your Enrollment List
Paste the roster PDF from the FAMAT site. This automatically imports names, IDs, divisions, and school name.
Loading only imports students not already listed in the table. To preserve your page order, they are added to the bottom of the list. This does not remove existing students or replace existing students. A different school is reviewed before import. To empty the whole list, click “Clear Students.”
Saved Rosters
Save up to three slots holding just the pasted rosters, which survive a refresh. To save an entire workspace, including teams, topics, and who's added, use Drafts instead.
Add One Student by Hand
FAMAT IDs are made up of School ID (4 digits), Student Number (3 digits), and Roster Level (1 digit, 1–6).
Everyone at a school shares one School ID, so it is only typed once. Fill it in for your first student and PDF Setup → School keeps it from then on. The box here will then turn read-only and School ID can only be changed in that menu.
Permission Slips
Import Permission Slips
Paste the names of everyone who is attending the competition, one per line. They are added to the PDF and everyone else is un-added. The full roster is preserved, and imports can be undone.
Build This List from a Spreadsheet
If your roster lives in a spreadsheet with a checkbox column for who is competing, one formula produces this whole list. Google Sheets =JOIN(CHAR(10), FILTER(namesRange, checkboxRange)) Excel 365 =TEXTJOIN(CHAR(10), TRUE, FILTER(namesRange, checkboxRange))

Replace namesRange with the column of eligible names and checkboxRange with the checkbox column beside it. For example, B2:B10 and D2:D10.

Both ranges must be one column and cover the same rows. Be sure to include student rows only: a header or totals row comes through as a name, and an offset range may switch on the wrong student.

Names on the Slips
How These Names Are Written

The defaults read a plain list correctly. Change these only when a paste comes back parsed the wrong way round, or split in the wrong place.

Names Are Written As
A line that only matches the other way round is still accepted, and reported as reversed after the parse.
Auto reads comma- and space-separated lists. Type the separator for odd formats like Last-First, or whitespace to force a split on spaces, which misreads multi-word names.
PDF Setup
School
The school name is printed on every sheet. The ID is checked against each student’s first four digits.
Loading a roster sets this to the most common prefix it finds. Any student whose ID starts differently is flagged in the list. Type a replacement and press Apply to update students whose school ID matches the old one.
Answer Columns
The nine ID columns on the sheet, left to right. Switch one off and it is left blank on every page.
School #
Student #
Level
Team
These are global: switching a digit off leaves it blank on every sheet. Per-student values still apply to the digits left on.
Text Font
Font for Name, School and Test. Bubbled ID digits keep their fixed-width font.
Printed text does not wrap. Check long names in the PDF preview.
File Name
What the generated PDF is called when it lands in your downloads. The .pdf ending is added for you.
Left empty, the PDF comes out as BubbledAnswerSheet.pdf.
Topic Tests Off
Topic Tests
Only the State and National conventions run topic tests. When on, a student can be given a named topic test and the PDF’s Test field prints that instead of the division name. There is one list per division this competition runs, plus Open, which belongs to nobody and is offered to everyone.
This replaces the division Test names for every student, not just the ones you assign a test to. While topic tests are on, a student’s Test field is whatever test they are given, and a student with no test assigned prints a blank Test field rather than their division’s name. Give them the TBD option below if the sheet should carry the division prefix with the test name left to be written in by hand.
Test Name is what prints in the Test field. Code is the 3-digit number bubbled on the sheet. Leave it blank to bubble nothing.
Each division’s prefix is on its own card, and follows the division’s name unless you type over it. Turning this off risks two divisions printing identical test names in the same round.
Each division gains a TBD choice that prints the prefix alone, leaving the test name and its code to be written on the sheet by hand afterwards.

            What Changes When I Switch?
        

          
Switching updates divisions, available topic tests and printed division digits using each student’s roster level. Your enrollment list and stored FAMAT IDs stay unchanged.

          
Students who change division lose their team assignments, and incompatible topic tests are cleared. Printed test names return to the preset defaults. Use Undo to reverse the whole switch, including any cleared assignments.
